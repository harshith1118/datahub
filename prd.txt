

# 📄 Product Requirement Document (PRD)

**Target Platform:** [Build with DataHub: The Agent Hackathon](https://datahub.devpost.com/) ($20,500 Prize Pool)

---

## 1. Executive Summary

When raw database schemas change in production (e.g., column renames or deletions), downstream data pipelines (dbt models, Airflow DAGs) break quietly. **DataHub-Sentinel** is an autonomous AI agent that monitors DataHub for schema diffs, analyzes downstream lineage, uses OpenCode to write a Git fix (Pull Request), and writes the resolution status back to the DataHub metadata graph.

## 3. Features & User Stories

### Feature A: DataHub Context Ingestion

* **User Story:** As an agent, I query DataHub’s MCP server or Python SDK to get schema drift events and downstream dbt/Airflow dependencies.
* **Requirements:**
* Connect to DataHub GMS using API token or local Docker instance.
* Query dataset schema versions and upstream/downstream lineage edges.



### Feature B: Automated Code Refactoring

* **User Story:** As an agent, I pass broken SQL files and schema diffs to OpenCode to automatically fix broken column names.
* **Requirements:**
* Scan local repo directory for `.sql` (dbt) or `.py` (Airflow) files.
* Pass the exact schema breaking change to OpenCode via CLI `/init` or non-interactive prompt mode.
* Refactor code without breaking business logic.



### Feature C: GitHub Pull Request Automation

* **User Story:** As an engineer, I want the agent to automatically submit a clean GitHub PR with the code fixes.
* **Requirements:**
* Create a new branch (`git checkout -b fix/datahub-schema-remediation`).
* Commit changes and open a PR via PyGithub/GitHub CLI.



### Feature D: DataHub Graph Write-Back *(Crucial for Winning!)*

* **User Story:** As a data team, I want DataHub updated so everyone knows a fix is pending.
* **Requirements:**
* Add a dataset tag/glossary term in DataHub: `STATUS: FIX_PENDING_PR_#42`.
* Add an operational incident report link pointing to the GitHub PR.

## 5. Master Prompt for OpenCode ("Vibe Code" Instructions)

To let OpenCode build this project for you, copy and paste the prompt below directly into your terminal or OpenCode session:

> **OpenCode Prompt:**
> *"Create a complete Python CLI project called `datahub-sentinel` under the Apache 2.0 license.
> 1. Set up `requirements.txt` with `acryl-datahub`, `pygithub`, `typer`, `pydantic`.
> 2. Create `src/datahub_client.py` using `datahub.emitter.mcp_builder` to fetch dataset lineage and write back tags like `Remediation_Pending` to DataHub entities.
> 3. Create `src/github_client.py` using PyGithub to git commit changed `.sql` files and open a Pull Request.
> 4. Create an `AGENTS.md` file explaining the architecture so you can run automated tasks.
> 5. Create `mock_data/broken_dbt_model.sql` and `src/main.py` CLI that ties the workflow together: read broken file -> fix column reference -> submit PR -> update DataHub tag."*
